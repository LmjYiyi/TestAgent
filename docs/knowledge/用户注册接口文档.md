# 接口场景  
**类型**:接口场景
**场景名**:普通用户注册
**关键词**:注册, 普通用户, 用户信息填写

场景描述：  
用户主动访问注册页面，输入必要信息完成注册。

个性化参数：  
无

步骤：  
1. 输入用户名、密码、手机号  
2. 点击注册按钮  
3. 显示注册成功提示  
4. 跳转到欢迎页  

---

# 接口场景  
**类型**:接口场景
**场景名**:渠道推广注册
**关键词**:注册, 邀请码, 渠道追踪

场景描述：  
通过专属渠道链接带入邀请码进行注册，并记录推广效果。

个性化参数：  
invite_code  

步骤：  
1. 用户通过渠道链接打开注册页  
2. 自动填充邀请码字段  
3. 用户填写其余注册信息  
4. 完成注册并记录来源信息  

---

# 接口场景  
**类型**:接口场景
**场景名**:第三方登录注册
**关键词**:注册, 第三方账号, OAuth

场景描述：  
通过微信、支付宝等第三方账号快速完成注册流程。

个性化参数：  
provider  

步骤：  
1. 点击“微信登录”或“支付宝登录”按钮  
2. 完成第三方授权并返回用户信息  
3. 系统创建新用户绑定第三方账号  
4. 自动跳转到首页并提示注册成功  

---

# 接口场景  
**类型**:接口场景
**场景名**:后台批量导入注册
**关键词**:注册, 后台导入, 批量创建

场景描述：  
由管理员通过后台系统批量导入Excel数据注册用户。

个性化参数：  
operator_id  

步骤：  
1. 管理员上传用户信息Excel表  
2. 系统解析数据并批量注册账号  
3. 返回注册成功和失败记录  
4. 默认生成密码并通过短信通知用户
