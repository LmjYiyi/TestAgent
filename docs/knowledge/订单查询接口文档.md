# 接口基本信息  =======全局参数  
**应用**:订单管理
**接口名**:order_query
**接口中文名**:订单查询
**URL**:/api/order/query
**版本号**:v1.0

---

# 通用请求参数  
**类型**:通用请求参数

| 参数名         | 类型     | 是否必输 | 描述           | 示例值           |
|----------------|----------|-----------|----------------|------------------|
| order_id       | string   | 是        | 订单ID         | 1234567890       |
| user_id        | string   | 是        | 用户ID         | 987654321        |
| start_date     | string   | 否        | 查询开始日期   | 2023-01-01       |
| end_date       | string   | 否        | 查询结束日期   | 2023-12-31       |
| status         | string   | 否        | 订单状态       | paid             |
| page           | integer  | 否        | 页码           | 1                |
| page_size      | integer  | 否        | 每页显示数量   | 20               |

---

# 通用响应参数  
**类型**:通用响应参数

| 参数名     | 类型   | 是否必输 | 描述             | 示例值           |
|------------|--------|----------|------------------|------------------|
| total      | integer | 是       | 符合条件的订单总数| 100              |
| orders     | array   | 是       | 订单列表         | [{...}, {...}]    |
| status     | string  | 是       | 查询状态         | success          |
| message    | string  | 否       | 错误信息提示     | 无记录           |

---

# 接口场景  
**类型**:接口场景
**场景名**:普通订单查询
**关键词**:查询, 订单, 用户

场景描述：  
用户通过提供订单ID和用户ID进行订单查询。

个性化参数：  
无  

步骤：  
1. 输入订单ID和用户ID  
2. 用户选择是否输入开始和结束日期  
3. 提交查询请求  
4. 系统返回符合条件的订单信息  

---

# 接口场景  
**类型**:接口场景
**场景名**:日期范围查询
**关键词**:查询, 订单, 日期

场景描述：  
用户可以通过提供开始日期和结束日期查询订单，查看指定日期范围内的所有订单。

个性化参数：  
start_date, end_date  

步骤：  
1. 用户输入开始日期和结束日期  
2. 提交查询请求  
3. 系统返回符合日期范围的订单信息  

---

# 接口场景  
**类型**:接口场景
**场景名**:订单状态查询
**关键词**:查询, 订单, 状态

场景描述：  
用户通过订单状态来查询特定状态的订单（如已付款、已发货等）。

个性化参数：  
status

1. 用户选择订单状态（如已付款、已发货等）  
2. 提交查询请求  
3. 系统返回符合状态的订单信息
