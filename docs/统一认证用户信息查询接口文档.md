### 统一认证用户信息查询

#### 接口信息
接口名称：UniformTeller.qryTellerInfo
接口中文名：统一认证用户信息查询
功能说明：提供统一的用户信息查询服务，支持通过多种标识符查询用户基本信息及认证状态。

#### 请求路径
|环境   |地址   |
|-------|-------|
|功能环境|https://xxxxx.icbc.sdc.com.cn/api/aam/uniformteller/qrytellerInfo/V1 |

#### 通用请求参数
|参数名	 |类型	 |是否必输|描述   |示例值 |
|-------|-------|-------|-------|-------|
|ssicType|string|是	|认证类型，1-统一认证号，2-身份证，3-香港身份证|1|
|ssicId	|string	|是	|认证号，根据不同的认证类型对应不同的证件号码	|392201198902121234|
|username|string|否	|登录用户名	|john.doe|
|email|string|否|注册邮箱|user@example.com|
|phone|string|否|注册手机号(带国际区号)|+8613812345678|
|biz_content|object|是|请求参数集合|-|
| ├─ serviceName|string	|是	|站点名称	|AAM|
| ├─ randomKey|string|是	|随机密钥	|smxxxxxxxxsm4|
| └─ timestamp|string|否|交易发生时间|2019-07-01 09:01:01|

#### 请求头
|参数名	|类型 |是否必输|描述|示例值|
|-------|-------|-------|-------|-------|
|X-Request-App|string|是|请求应用名|F-CCPS|
|X-Request-Id|string|是|请求应用号|2010434|

#### 通用响应参数
|参数名	|类型 |是否必输|描述|示例值|
|-------|-------|-------|-------|-------|
|return_code|string|是|返回码，成功返回0，失败返回非0|0|
|return_msg|string|是|返回信息|校验身份信息失败|
|return_msg|string|是|返回信息|校验身份信息失败|
| data | object |否|返回对象 |--|
| ├─ field1 | string |是| 信息1 |--|
| ├─ field2 | object |否| 信息2 |--|
| │  ├─ sub_field1 | int |是| 子信息1 |--|
| │  └─ sub_field2 | bool |否| 子信息2 |--|
| └─ field3 | string |是| 信息3 |--|

#### 请求示例
```json
{
  "ssicType": "1",
  "ssicId": "392201198902121234",
  "username": "john.doe",
  "email": "user@example.com",
  "phone": "+8613812345678",
  "biz_content": {
    "serviceName": "AAM",
    "randomKey": "smxxxxxxxxsm4",
    "timestamp": "2019-07-01 09:01:01"
  }
}
```

#### 成功响应示例
```json
{
  "return_code": "0",
  "return_msg": "请求处理成功",
  "data": {
    "field1": "示例信息值",
    "field2": {
      "sub_field1": 100,
      "sub_field2": true
    },
    "field3": "另一示例值"
  }
}
```

#### 异常响应示例
```json
{
  "return_code": "1001",
  "return_msg": "校验身份信息失败",
  "data": null
}
```

#### 场景分支

##### 场景分支1
1. 场景分支名：验证统一认证号分支
2. 准备条件（GIVEN）
获取开关表里接口名称为UniformTeller.qryTellerInfo的那条信息，将status字段设置成1-启用
3. 测试用例（WHEN）
该分支测试验证类型为1-统一认证号的认证结果，将请求参数里对应字段改为如下参数：
```json
{
    "ssicType": "1",
    "ssicId": "002285023",
}
 ```
4. 测试结果（THEN）
    返回结果为成功的响应参数即为成功，同第7章节响应示例
