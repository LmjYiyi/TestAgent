# 信用卡转账支付测试接口需求文档
**文档标题**:关于信用卡转账支付接口 (CreditCardService.transferPay) 新增大额转账备注字段的功能需求规格说明
**文档版本**:1.1
**需求ID**:TCGT-REQ-2025-116
**发布日期**:2025-07-26

## 1.变更背景与业务目标 
**背景**:大额转账（≥5000元）缺乏备注信息导致客服对账困难，业务部门要求新增备注字段用于交易说明。
**业务目标**:通过收集大额转账备注，提升交易可追溯性，降低客服对账成本。

## 2.需求范围
本次需求变更仅涉及**信用卡转账支付接口 (CreditCardService.transferPay)**。
具体的变更是在**请求参数中新增选输字段，并添加联动校验逻辑**。

## 3.详细功能描述
在请求参数中新增选输字段：
**字段名**：`large_remark`
**类型**：string
**是否必输**：选输（但存在联动条件）
**最大长度**：50
**描述**：大额转账备注，仅当`transfer_amount≥5000元`时需传入。

**联动校验逻辑**：
若`transfer_amount≥5000元`且`large_remark`为空，返回`return_code=ERR4002`，`return_msg=“大额转账需填写备注”`。
若`transfer_amount<5000元`，`large_remark`可忽略，不影响交易。

## 4.验收标准 (Acceptance Criteria)
1. 转账金额=6000元且`large_remark=“工资转账”`时，交易正常执行（return_code=0）。
2. 转账金额=6000元且`large_remark`为空时，返回`return_code=ERR4002`，`return_msg=“大额转账需填写备注”`。
3. 转账金额=4000元且`large_remark`为空时，交易正常执行（忽略该字段）。
4. `large_remark`长度超过50字符时，返回`return_code=ERR4003`，`return_msg=“备注长度不能超过50字符”`。
