# 信用卡转账支付测试接口需求文档
**文档标题**: 关于信用卡转账支付接口 (CreditCardService.transferPay) 新增附言信息字段的功能需求规格说明  
**文档版本**: 1.1  
**需求ID**: TCGT-REQ-2025-117  
**发布日期**: 2025-08-13  

## 1. 变更背景与业务目标
**背景**: 部分持卡人在转账时希望在交易中附加简短说明，便于收款方识别资金用途。现有接口未提供此类信息输入，业务部门提出新增字段需求。  
**业务目标**: 增加转账附言信息字段，方便交易双方对账与备注。  

## 2. 需求范围
本次变更仅涉及**信用卡转账支付接口 (CreditCardService.transferPay)**，
在请求参数中新增一个选输字段，不影响现有必输字段和逻辑处理。  

## 3. 详细功能描述
新增选输字段：  
- **字段名**：`transfer_note`  
- **类型**：string  
- **是否必输**：选输  
- **最大长度**：60  
- **描述**：转账附言信息，可用于简要说明转账原因或备注。  

**逻辑变更**：  
- 若填写`transfer_note`，则该内容随交易请求一并保存，并可在交易明细中查询。  
- 若未填写，交易流程与原逻辑一致，不影响处理。  

## 4. 验收标准 (Acceptance Criteria)
1. 填写`transfer_note=“礼金”`时，交易正常执行（`return_code=0`），交易明细可查询到该备注。  
2. 未填写`transfer_note`时，交易正常执行（`return_code=0`），交易明细中该字段为空。  
3. `transfer_note`长度超过60字符时，返回`return_code=ERR4010`，`return_msg=“附言信息长度超限”`。
