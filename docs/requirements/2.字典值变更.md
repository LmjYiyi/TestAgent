# 信用卡转账支付测试接口需求文档
**文档标题**:关于信用卡转账支付接口 (CreditCardService.transferPay) 新增风控拦截状态码的功能需求规格说明
**文档版本**:1.1
**需求ID**:TCGT-REQ-2025-114
**发布日期**:2025-07-24

## 1.变更背景与业务目标
**背景**:近期出现多笔异常转账交易（如单日高频转账），需新增风控拦截逻辑并明确错误提示。
**业务目标**:通过实时风控拦截异常交易，降低欺诈风险，提升接口安全性。

## 2.需求范围
本次需求变更仅涉及**信用卡转账支付接口 (CreditCardService.transferPay)**。
具体的变更是针对**响应参数`return_code`字典值新增**及配套风控逻辑。

## 3.详细功能描述
1. **新增风控逻辑**当检测到“单日转账次数≥5次”时，触发风控拦截。
2. **响应参数`return_code`字典值新增**：
   - 新增值：`ERR5001`
   - 描述：交易触发风控，请稍后重试
   - 原字典值（如0=成功、ERR1001=余额不足）保持不变。

当上游系统触发风控条件时，接口返回`return_code=ERR5001`，`return_msg=“交易触发风控，请稍后重试”`，交易终止。

## 4.验收标准 (Acceptance Criteria)
1. 单日转账≤4次时，交易正常执行（return_code=0，可用余额扣减正确）。
2. 单日转账第5次时，返回`return_code=ERR5001`，`return_msg=“交易触发风控，请稍后重试”`，可用余额无变动。
3. 存量场景（如正常交易、余额不足）的`return_code`仍为原定义值，无字典值串用。
4. 接口请求参数无新增，响应参数结构与原版本一致。
