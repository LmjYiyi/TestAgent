# 信用卡转账支付测试接口需求文档
**文档标题**:关于信用卡转账支付接口 (CreditCardService.transferPay) 新增转账用途字段的功能需求规格说明
**文档版本**:1.1
**需求ID**:TCGT-REQ-2025-115
**发布日期**:2025-07-25

## 1.变更背景与业务目标  
**背景**:监管要求所有转账交易需登记用途，现有接口缺少必填的“转账用途”字段。
**业务目标**:满足监管合规要求，确保每笔交易可追溯，避免违规风险。

## 2.需求范围  
本次需求变更仅涉及**信用卡转账支付接口 (CreditCardService.transferPay)**。
具体的变更是在**请求参数`InfoParams`对象下新增必输字段**。

## 3.详细功能描述  
在请求参数`InfoParams`（交易信息参数）中新增必输字段：
**字段名**：`transfer_purpose`
**类型**：string
**是否必输**：是
**最大长度**：20
**字典值**：1=消费、2=还款、3=转账、4=其他
**描述**：转账用途，上游系统必须按字典值传入。

接口后端逻辑需校验该字段是否存在且值合法，若缺失或非法则返回`return_code=ERR4001`，`return_msg=“转账用途必填且需为合法值”`。

## 4.验收标准 (Acceptance Criteria)
1. 传入`transfer_purpose=1`（消费）时，交易正常执行（return_code=0）。
2. 未传入`transfer_purpose`时，返回`return_code=ERR4001`，`return_msg=“转账用途必填且需为合法值”`。
3. 传入`transfer_purpose=5`（非法值）时，返回同上错误。
4. 响应参数中无该字段，接口其他逻辑（如金额扣减）不受影响。
