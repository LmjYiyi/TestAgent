# 信用卡转账支付测试接口需求文档
**文档标题**:关于信用卡转账支付接口 (CreditCardService.transferPay) 优化手续费计算逻辑的功能需求规格说明
**文档版本**:1.1
**需求ID**:TCGT-REQ-2025-113
**发布日期**:2025-07-23

## 1.变更背景与业务目标
**背景**: 现有异地转账手续费规则（5元与转账金额1%的最大值）用户反馈过高，业务部门要求下调手续费标准以提升用户体验。
**业务目标**: 通过降低异地转账手续费，提高信用卡转账交易量，增强用户满意度。

## 2.需求范围 
本次需求变更仅涉及**信用卡转账支付接口 (CreditCardService.transferPay)**。
具体的变更是针对**手续费计算逻辑**，无字段新增/删除，无字典值变动。

## 3.详细功能描述 
调整接口中“异地手续费计算逻辑”：
**原规则**：手续费 = max(5元, 转账金额 × 1%)
**新规则**：手续费 = max(3元, 转账金额 × 0.5%)

其他逻辑（如金额扣减、参数校验）保持不变，接口请求/响应参数结构无调整。

## 4. 验收标准 (Acceptance Criteria)
1. 当转账金额=100元时，手续费=max(3, 100×0.5%)=3元，可用余额扣减=100+3=103元。
2. 当转账金额=2000元时，手续费=max(3, 2000×0.5%)=10元，可用余额扣减=2000+10=2010元。
3. 非异地场景（chk_local_flag=0）或fee_type=0时，手续费仍为0，逻辑不受影响。
4. 接口响应参数（return_code、usable_amount等）格式与原版本一致，无新增字段。
